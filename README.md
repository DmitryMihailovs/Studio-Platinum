# STUDIO PLATINUM — Luxury Furniture Design Portfolio & Concept Generator

A modern React application built with TypeScript, Vite, Tailwind CSS, and Lucide React for **Studio Platinum** (`SIA STUDIO PLATINUM`), specializing in bespoke premium furniture design.

## Features

- **Trilingual Support (RU / LV / EN)**: Seamlessly toggle between Russian, Latvian, and English with state persistent across sessions.
- **Bespoke Portfolio Gallery**: Responsive bento grid showcasing 15 high-definition studio furniture projects (`images/1.jpeg` - `images/15.jpg`).
- **Interactive Lightbox Modal**: High-resolution image viewer with an active thumbnail carousel, keyboard navigation (left/right arrows, escape), image counter, and image zoom.
- **Furniture Idea Generator ("Генератор идеи мебели")**: Interactive concept visualization engine that converts user text descriptions into architectural SVG previews, complete with material recommendations, dimension specifications, and direct WhatsApp / Telegram consultation links.
- **About Studio & Craftsmanship**: Showcase of studio philosophy and bespoke craftsmanship with high-resolution designer photography.
- **Direct Client Contacts**: One-click action buttons for WhatsApp, Telegram, Facebook, Instagram, Phone, and Email.
- **Content Manager**: Integrated client-side portfolio editor allowing addition and deletion of gallery works with local persistence.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS v4 + Custom Luxury Theme Tokens
- **Icons**: Lucide React
